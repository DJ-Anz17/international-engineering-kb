# 变更事件记录工作卡（演示资料）

> 本文件仅用于演示知识库检索与引用，不代表任何具体合同的条款或法定期限。

## 事件记录

现场团队发现可能构成变更的指令后，应在当日建立事件编号，保存指令原件、收发记录、会议纪要、照片、日报和受影响工作的基准计划信息。

## 合同核验

合同经理应核对所适用合同版本及特别条件，确认：指令是否来自有权人员；是否要求书面通知；通知的起算点、期限、收件人、送达地址和内容；是否存在逾期导致权利受限的条款。

## 影响记录

成本记录应与正常工作分开，包括人工工时、设备台班、材料、分包、等待、返工和现场管理成本。进度记录应说明受影响活动、逻辑关系、浮时和减损措施。

## 控制原则

先发出权利保留和事实通知，再按合同要求补充详细资料。任何期限都必须回到已签署合同和特别条件核验，不得把其他项目或范本的期限直接套用。
