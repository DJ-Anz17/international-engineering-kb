# learn-from-materials 功能融合说明

参考项目：[`dmoshehun-prog/learn-from-materials`](https://github.com/dmoshehun-prog/learn-from-materials)，对比提交 `9f27958623705d791d69c353a8652275c958e998`。

## 已融合

| 参考能力 | 本知识库实现 |
|---|---|
| 多格式材料 | 新增 EPUB、RTF、PPTM、MOBI/AZW/AZW3；保留 PDF、Office、网页和文本 |
| 细粒度来源映射 | 每个片段保留文档 ID、来源 ID、定位和内容 SHA-256 |
| 材料安全扫描 | 检测提示注入、角色覆盖、外传要求、命令、隐藏 Unicode 和主动 HTML |
| ZIP 容器保护 | DOCX、PPTX/PPTM、XLSX、EPUB 读取前检查路径穿越、加密、体积和压缩比 |
| 快速/系统学习 | 新增“材料快速了解”“材料系统学习（分主题）”两个带引用模式 |
| 动态自检 | 新增“材料学习自检”模式，覆盖记忆、解释、应用和迁移 |
| 单材料学习 | 网页可选择一份资料，检索和 AI 分析严格限定该文档 |
| 本地笔记 | 检索证据一键收藏到浏览器 localStorage，可导出 JSON |
| 离线学习页 | 导出 `.learnkb.zip`，包含可搜索和记录笔记的单文件 `learning.html` |
| 指纹与增量 | 沿用现有 SHA-256 增量索引，并在学习包中输出 manifest/source map |

## 兼容性取舍

参考项目是由 Agent 驱动的 Python 3.10+ 学习页生成流水线；当前知识库是 Python 3.9、SQLite、Ollama 向量检索和多模型问答服务。为保持现有本地部署稳定，本次没有直接复制其大型渲染器，而是把关键能力重新接入现有数据库、网页、CLI 和检索过滤器。

“材料系统学习（分主题）”只对当前命中的原文范围负责。长书应按章节或主题分批学习，不能把有限检索片段描述为整本材料的全量覆盖。`.learnkb.zip` 会完整导出全部已索引文字，但扫描图片、公式、复杂表格与图表仍需要 OCR 或视觉复核。

## 数据与隐私

- 学习包保存在 `data/learning-packs/`，可随时重建；
- 浏览器笔记只保存在当前浏览器，不提供云同步；
- 原始资料和完整学习包不会自动发送给云端模型；
- 使用云端回答模型时，仍只有问题和检索命中的证据片段进入请求；
- 安全扫描只标记材料，不删除或执行其中内容。
